# PROFILE: data-analysis（データ分析）— 雛形

> 状態: **雛形のみ。** 再現可能な分析手順の標準形は Phase 6 で定める。

集計・統計・可視化を伴う分析業務を想定する。

## 入力

- データセット（小さな公開データのみ `kind: file`。顧客データは `kind: reference`）
- 分析の問い、母集団の定義

## 受入基準の書き方

| 品質軸 | 典型的な基準 | 検証方法 |
|---|---|---|
| spec_conformance | 問いに答えている、指定の指標を使っている | `inspection` |
| correctness | スクリプトを再実行して同じ数値が出る | `command` |
| completeness | 母集団・除外条件・欠損の扱いを明記 | `inspection` |

## 分析固有の規則

- 欠損は 0 として扱わない。欠損は欠損として数え、報告する。
- 比率は分母（母集団）と一緒に示す。異なる母集団の件数を足し合わせない。
- 数値は再実行可能なスクリプトの出力を証拠とし、手で転記した数値を証拠にしない。
- 例示の計算は「例示」と明記し、予測として扱わない。
